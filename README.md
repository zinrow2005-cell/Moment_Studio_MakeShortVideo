# 拾光˙剪映 V6.13 — 最低 1080P 輸出

- 1080P（Full HD）為預設與最低選項：直式 1080×1920，橫式 1920×1080，目標 14 Mbps。
- 新增 1440P（2K）：直式 1440×2560，橫式 2560×1440，目標 22 Mbps。
- 新增 2160P（4K）：直式 2160×3840，橫式 3840×2160，目標 35 Mbps。
- 移除 540P、720P 的畫質選項及其輸出設定，保留原有照片、主題、封面、音樂及專案資料功能。
- 2K／4K 可能超出手機可用記憶體或 MediaRecorder 的編碼能力。高解析度無法支援時應顯示失敗訊息，不自動降成 720P。
- 以上碼率僅為瀏覽器編碼器請求值，非硬性保證；原始照片不清楚也無法藉放大輸出補回細節。
- 已檢查 JS 語法、靜態引用、PWA 快取與 ZIP 完整性；未做 iOS／Android 真機匯出。


## V6.14 匯出進度全螢幕遮罩
匯出時使用全螢幕半透明灰底與中央獨立進度視窗，顯示狀態、百分比、進度條與取消。完成、取消及驗證失敗自動關閉；錄製完成後的驗證階段會持續顯示。此版本未修改音樂庫及錄製編碼器。
