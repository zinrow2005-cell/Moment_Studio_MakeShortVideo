# 拾光 × Moment Studio V5.87｜手機主題顯示與音樂庫修正版

- 與電腦版共用 24 種主題、照片、封面、音樂軸與匯出引擎，手機主題抽屜與桌面收合狀態分離。
- 修復手機主題抽屜被舊 CSS 覆蓋造成空白／無法選取的問題。
- 音樂中心 Openverse 搜尋從 16 秒提升到 28 秒，暫時失敗重試一次，並清楚顯示錯誤。
- 連線確實失敗時提供 Openverse 官方搜尋及本機音樂匯入，未使用不安全的公開 CORS 代理。
- **網路限制**：純 GitHub Pages 無法保證第三方 API 在每個手機網路均可存取，Openverse 的服務及授權仍受第三方限制。
- 在 GitHub Pages 更新後，請清除 Safari/Chrome 的舊頁快取並重新整理。
